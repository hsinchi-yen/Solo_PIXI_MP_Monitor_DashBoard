## 3. 既有數字沒有改變

- **比對方式**：在 v3.1.0 部署前，先記下舊版 API 的結果作為基準，存放在 `dbbackup/261020/old_api_baseline/`。這次把同一份資料還原到本機後，用 v3.2.0 重新比對。
- **結果**：238 項中 237 項完全相同。
- **唯一不同的一項是 `fail-analysis[all]`**：兩列內容相同，只是順序對調。這兩列是 `WIFI_TX_VERIFY_ALL / EVM fail` 的 ERR_29 和 ERR_33，次數都是 70 次。
  - 原因：失敗分析只依次數排序，次數相同時沒有規定先後，所以順序本來就不固定。
  - 範圍：這段查詢這次沒有修改，v3.1.0 也是一樣的情況。
- **一次通過率與正式機唯讀查詢的結果一致**：
