Data Alignment

⚖️ 運作原理
Target Total：輸入每個工單的計畫生產數量。未被測試的數量 (Gap = Target − Tested) 會自動被計算為潛在的不良品（Aligned FAIL = Raw FAIL + Gap）。
PASS 優先認列 (Raw KPI)：系統會在產生 Raw KPI 時自動處理，同一 (Work Order, MAC1) 只要曾有 PASS 記錄，不論時間先後皆優先計為 PASS。
雲端同步儲存：設定的 Target Total 直接寫入後端 PostgreSQL 資料庫，支援跨裝置即時同步，無需登入。

Work Order Alignment — Target vs Tested

Work Order Last Test Tested PASS FAIL STOP Target Total Gap (Untested) STOP→PASS Aligned PASS Aligned FAIL Aligned Yield %
* STOP→PASS：僅為輔助參考資訊，顯示有多少台設備受惠於「PASS 優先認列」而被挽回為 PASS（如 Golden Sample 複驗），此數值已內含於 Raw PASS 之中，不再重複相加。
* 設定的 Target Total 儲存於伺服器資料庫，點擊 Save All 後跨裝置即可同步，即使更換電腦資料也不會遺失。
